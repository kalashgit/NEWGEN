# NEWGEN

Unified, modular asset-intelligence factory for 2D sprites, procedural/AI 3D reconstruction, component-aware 3D modeling and Godot gameplay assets.

**State:** experimental. No Golden approval, mass-production throughput or paid provider is implied by these imported scripts.

See `docs/HANDOFF.md` for legacy provenance, `docs/ARCHITECTURE.md` for the integration plan, and `integrations/last_light/` for a preserved research snapshot of the previous LAST LIGHT generators. No original source-image files or model weights are committed.
